## 🌍 Overview

This project presents a **Severity-Aware Multi-Pipeline IoT Data Processing Framework** designed for industrial environments.

Instead of treating all sensor data equally, the system:

✔ Classifies events using **Edge-based Fuzzy Logic**  
✔ Dynamically routes them to appropriate processing pipelines  
✔ Applies **LLM-based reasoning (Phi-3 Mini via Ollama)** for high-severity insights  
✔ Logs critical actions for intelligent analysis  

The architecture reduces latency, optimizes throughput, and enhances interpretability.
